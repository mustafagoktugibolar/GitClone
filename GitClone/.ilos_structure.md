# .ilos Directory Structure and File Purposes

This document explains the purpose and example contents of the main files and folders inside the `.ilos` directory.

---

## 1. `HEAD`
- **Purpose:** Points to the currently checked out branch.
- **Example Content:**
  ```
  ref: refs/heads/master
  ```
  This means you are currently on the `master` branch.

---

## 2. `config.json`
- **Purpose:** Stores repository settings and user information.
- **Example Content:**
  ```json
  {
    "user": {
      "name": "Goktug",
      "email": "goktug@example.com"
    },
    "remote": "https://github.com/example/repo.git"
  }
  ```

---

## 3. `index`
- **Purpose:** The staging area. Keeps a list of files staged for commit and their hashes.
- **Example Content:**
  ```
  hello.txt abcd1234...
  world.txt efgh5678...
  ```
  Each line contains a file name and its blob hash. This is used when creating a commit.

---

## 4. `objects`
- **Purpose:** Stores all content (commits, trees, blobs) as hashed files.
- **Structure:**
  - `objects/1a/2b3c4d5e...` (first two characters of the hash as folder, the rest as file)
- **Objects:**
  - **Blob:** File content (e.g., the contents of `hello.txt`)
  - **Tree:** A directory listing (name, type, hash for each entry)
  - **Commit:** Commit message, parent commit, tree hash, author info
- **Tree Example:**
  ```
  100644 blob abcd1234...    hello.txt
  100644 blob efgh5678...    world.txt
  ```

---

## 5. `refs`
- **Purpose:** Stores branch and tag references. Each branch points to the latest commit hash.
- **Structure:**
  - `refs/heads/master` file: Contains the latest commit hash for the branch.
- **Example Content:**
  ```
  1a2b3c4d5e...
  ```

---

## Summary
- **HEAD:** Current branch pointer
- **config.json:** Settings and user info
- **index:** Staged files and their hashes
- **objects:** All content (commit/tree/blob) as hashed files
- **refs:** Branches and their latest commit hashes

Everything is linked by hashes. File lists and contents are not stored directly in refs, but in tree and blob objects.
